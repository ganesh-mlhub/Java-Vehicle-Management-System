# Vehicle Management System

## 📌 Project Overview

The Vehicle Management System is a Java-based project that demonstrates the implementation of Object-Oriented Programming (OOP) concepts such as Abstract Classes, Inheritance, Method Overriding, and Polymorphism. Different vehicle types share common properties while providing their own implementations for fuel efficiency calculation and sound generation.

## 🎯 Objective

To implement the following Java OOP concepts:

- Abstract Classes
- Abstract Methods
- Inheritance
- Method Overriding
- Polymorphism
- Constructors

---

## 📝 Problem Statement

Design a Vehicle Management System where different vehicles share common properties but have different implementations for fuel efficiency calculation and sound generation.

---

## 🏗️ Classes Used

### 1. Vehicle (Abstract Class)

#### Attributes
- `brand`
- `speed`
- `fuelCapacity`

#### Methods
- `displayInfo()`
- `calculateFuelEfficiency()`
- `makeSound()`
